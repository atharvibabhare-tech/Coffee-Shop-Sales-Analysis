# ☕ Coffee Shop Sales Analysis

## 📌 Overview
This project analyzes coffee shop sales data to understand customer purchasing behavior, product performance, monthly trends, and overall business insights. The analysis is performed using Python libraries such as Pandas, Matplotlib, and Seaborn, along with interactive visualization using Streamlit.

The project includes:
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Sales trend visualization
- Customer and product analysis
- Interactive dashboard using Streamlit

---

## 🚀 Features
- 📊 Analyze total sales and revenue trends  
- ☕ Identify best-selling coffee products  
- 📅 Monthly and daily sales analysis  
- 👥 Customer purchasing behavior insights  
- 📈 Interactive charts and visualizations  
- 🌐 Streamlit dashboard for easy data exploration  

---

## 🛠️ Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Streamlit  
- Jupyter Notebook
